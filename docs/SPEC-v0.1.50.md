## Changes (version 0.1.49 → 0.1.50; bump every place listed in SPEC-v0.1.49 C4 plus docs)

### R1. OutputAnchor carries the confirmed body; new auto-copy order
- `OutputAnchor` gains `Rectangle Body` (client px, may be empty until confirmed). Serialization: keep `A1|pid|ticks|session|x|y|w|h|learnedTicks` for the copy-worker output; add `A2|pid|ticks|session|x|y|w|h|learnedTicks|bx|by|bw|bh` produced by SlaveForm after confirmation and passed to the auto-copy worker. `TryParse` accepts both; `Matches` unchanged.
- Auto-copy worker order becomes: resolve window → identity/client-size check → **occlusion check at the stored body centre** (`WindowFromPhysicalPoint`) → idle-input check → one click at the stored body centre → wait ~150 ms → **capture fresh frame → `FindBodyAt(frame, anchor.ClientPoint)` must succeed, contain the click point, and match the stored body within ±8 px on every edge** (else `AUTO_COPY_BODY_UNCONFIRMED` / new `AUTO_COPY_BODY_MOVED`; **no keys are sent in that case**) → foreground root == hwnd → Ctrl+A, Ctrl+C → clipboard sequence/owner checks as before. Rationale: the click deselects any highlighted text so the neutral-background body check is repeatable, and the click point is the user's own learned position on a window whose identity, client size and occlusion were verified live. Document this ordering honestly in README/HANDOFF (identity/size/occlusion are verified before the click; pixels are verified before any key is sent).
- Occlusion failure detail: resolve the occluding window's root → `GetWindowThreadProcessId` → process name (sanitize to `[A-Za-z0-9_.-]{1,64}`), detail `OCCLUDER|<name>`; if it is our own process, detail `OCCLUDER|SELF`.
- On any failure after the fresh capture, return the worker frame PNG to the UI: extend the OB1 wire with an optional 6th tab-separated field (base64 PNG, ≤ 8 MiB) that only the auto-copy verb fills; parser accepts 5 or 6 fields; existing self-tests keep passing. `OutputBufferResult` cannot change (Link type) — expose via `OutputAutoCopy.FrameOf(result)` like `AnchorOf`, or return a small Slave-side wrapper from `AutoCopyAsync`.
