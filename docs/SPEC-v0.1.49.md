### C2. Transcript comparison (Agent L)
New `TranscriptComparison.cs`, pure, no UI, no I/O:
- `internal sealed class TranscriptComparison { internal static TranscriptComparison Compare(string fullText, string transcript, int tailLines = 600); IReadOnlyList<Line> Lines; int Exact, Normalized, Near, Missing, Empty; bool OrderPreserved; string Render(); string Summary(); }`
- `Line { string Transcript; string Status /* EXACT|NORMALIZED|NEAR|MISSING|EMPTY */; int MatchedIndex /* -1 if none, index into full text lines */; string Matched; int Distance; string Diff; }`.
- Normalization for `NORMALIZED`: trim, collapse internal whitespace runs to one space, case-sensitive. `NEAR`: Levenshtein distance ≤ max(2, 10% of length) against normalized lines in the tail window; pick minimum; `Diff` = short marker of first differing char position and both fragments (≤ 80 chars each). `MISSING` otherwise. `EMPTY` for blank transcript lines. `OrderPreserved` = matched indices are non-decreasing.
- `Render()` = Korean human-readable per-line report (contains text — UI/bundle only). `Summary()` = metadata only, e.g. `T1|lines|exact|normalized|near|missing|empty|order` — safe for the log.
- Line splitting: `\r\n`, `\n`, `\r`. Cap transcript at 2000 lines, full text tail at `tailLines`. Must be O(lines_transcript × tailLines × len) fine for 12×600.
- Self-test with synthetic texts covering all statuses and order detection; register in `LinkSelfTest.Run()`.

### C3. Auto copy + anchor learning (Agent S)
New `OutputAutoCopy.cs` (Slave). Design principles: never click stored coordinates blindly; every live step re-verifies; abort on any interference; exactly one click, exactly one Ctrl+A and one Ctrl+C; all keys released in `finally`; the worker is a separate process (existing `TryRunWorker` pattern in OutputBufferCapture.cs) so a hang cannot freeze the UI.
- `internal sealed class OutputAnchor { int Pid; long StartUtcTicks; int SessionId; Point ClientPoint; Size ClientSize; DateTime LearnedUtc; string Serialize(); static bool TryParse(string, out OutputAnchor); }` — serialization `A1|pid|ticks|session|x|y|w|h|learnedTicks`.
- Learning: extend the existing `--powersi-output-copy` worker so that when `TryReadUserCopy` succeeds it also samples, in this order, `GetForegroundWindow()` (must equal resolved root hwnd or be a child of it via `IsChild`/root walk with `GetAncestor(GA_ROOT)`), `GetPhysicalCursorPos` → `ScreenToClient(root)`, `GetClientRect(root)`. If all succeed and the point is inside the client rect, append to the OB1 detail: `SOURCE_PID_MATCH|` + anchor serialization; else `SOURCE_PID_MATCH|ANCHOR_NONE|reason`. Extend `OutputBufferResult` parsing so `ReadAsync` exposes `internal OutputAnchor Anchor` (null when none) without breaking existing self-tests; the existing Detail text before the first `|` must stay `SOURCE_PID_MATCH`. The anchor is only a hint; phase 2 confirms it with `OutputPaneImage.FindBodyAt` on the run's frame before storing.
- Worker verb `--powersi-output-auto-copy <sessionId> <pidlist> <baselineSeq> <anchorSerialized>` implemented in OutputAutoCopy, dispatched from `OutputBufferCapture.TryRunWorker`. Steps inside the worker (all with `MonitorException`-style fixed codes, prefix `AUTO_COPY_`):
  1. `PowerSiScreenCapture.ResolveWindow(args)` (existing; fresh HWND). Check anchor pid/start/session match the resolved target; `GetClientRect` must equal `anchor.ClientSize` → else `AUTO_COPY_WINDOW_CHANGED`. Check `IsWindowVisible`, not `IsIconic`.
  2. Capture a fresh frame in-process using the existing capture routine (`PowerSiScreenCapture.CaptureWindow` or whatever internal method the worker path uses; do not spawn another worker) → `OutputPaneImage.FindBodyAt(frame, anchor.ClientPoint, ct, out diag)` → body rect; failure → `AUTO_COPY_BODY_UNCONFIRMED` with `diag.Summary()` as detail.
  3. Click target = body center in client coords; `ClientToScreen`. Pre-checks: `GetAsyncKeyState` shows no mouse buttons / Ctrl / Shift / Alt / LWin / RWin held (`AUTO_COPY_INPUT_BUSY`); `WindowFromPhysicalPoint(target)` root (`GetAncestor(GA_ROOT)`) must equal hwnd (`AUTO_COPY_OCCLUDED`); `SM_SWAPBUTTON` read once.
  4. Save cursor pos; `SetPhysicalCursorPos(target)`; read back exact (`AUTO_COPY_CURSOR_NOT_SET`); one `SendInput` LEFTDOWN, ~60 ms, LEFTUP (respect swap button like Master `MouseClickInput`). Wait ≤ 600 ms polling 20 ms until `GetForegroundWindow()` root == hwnd else `AUTO_COPY_FOREGROUND_FAILED`. Re-check cursor still at target (`AUTO_COPY_CURSOR_MOVED`).
  5. Keys via `SendInput` KEYBDINPUT with scan codes from `MapVirtualKey` and `KEYEVENTF_SCANCODE`: CTRL↓ A↓ A↑ CTRL↑, 80 ms, then CTRL↓ C↓ C↑ CTRL↑. Verify foreground root unchanged before each chord. `finally`: send CTRL↑ (and A↑/C↑ if a down was sent without up).
  6. Wait ≤ 2000 ms polling 50 ms for `GetClipboardSequenceNumber() != baseline`; none → `AUTO_COPY_NO_CLIPBOARD`. Then `OutputBufferCapture.TryReadUserCopy(inventory-equivalent check, baseline, out result)` — reuse the existing owner PID/start/session gate (refactor into a shared static if needed, keep behaviour). Foreign owner → `AUTO_COPY_CLIPBOARD_FOREIGN`.
  7. Success result: `Code="AUTO_COPY_READ"`, `Method="AUTO_CLIPBOARD"`, `Detail="A2|anchorX|anchorY|bodyX|bodyY|bodyW|bodyH|clickX|clickY|" + diag.Summary()`. Return via the same `OB1` wire as the other verbs. Do not restore the clipboard. Restore the cursor position at the end (best effort, ignore failure) — document this in the API comment.
  Whole worker budget 8 s (`ReadAsync`-style timeout); UI-side helper `internal static Task<OutputBufferResult> AutoCopyAsync(ProcessInventory inventory, OutputAnchor anchor, uint baseline, CancellationToken ct)` in OutputAutoCopy that spawns the worker and parses.
- Self-tests (`OutputAutoCopy.SelfTest()`, call from `OutputBufferCapture.SelfTest()` so Program.cs needn't change): anchor serialize/parse round-trip and rejection of malformed; OB1 detail parsing with/without anchor; key-chord composition (pure, describe the INPUT array without sending); and a **live test** using an owned WinForms Form with a multiline TextBox containing known text: show it, `Activate()`, wait ≤1 s for `GetForegroundWindow()==form.Handle`; if it never becomes foreground print `SKIP: live input test (no interactive foreground)` and return success; otherwise run the click+chords against the TextBox center with the same injector code (skip window-resolution steps, pass hwnd directly) and assert the clipboard now holds the exact text and `GetClipboardSequenceNumber` changed. Before touching the clipboard in the live test save nothing (documented). Keep the live test under 5 s.
